# ADR-0014 云端开发环境：在 DOKS 上部署一套织境并兼作开发环境

- 状态：已接受（030；首次完整部署后的实测结论补记于 `specs/030-doks-deploy/research.md`）
- 日期：2026-11-11
- 决策人：@stephenhuo-code
- 影响特性：030（029 阿里云测试环境可复用其脚本与参数化方式）
- 相关宪法条款：部署约束（v2.3.0“自有云端开发环境”）、I（测试与覆盖率）、III（开源许可）、IV（凭证）

## 背景

负责人的开发机 devbox-0 运行在 DigitalOcean Kubernetes（DOKS）中：约 1.5 核、2 GB 内存，没有 Docker，无法运行本地 kind 部署。
需要一套可通过公网域名访问的织境环境，同时作为日常开发环境：改代码不经 git 即可生效，构建与测试在集群内执行，空闲时释放计算资源。
需求与决策过程见 `specs/030-doks-deploy/`（spec、research R1–R19、R17a）。

## 决定

1. **一套环境**：复用现有 helmfile 与组件 Chart，新增 `cloud` 环境与各组件 `values/cloud.yaml.gotmpl`；本地 `local` / `lite` 渲染结果
   与基线逐字节一致（`tools/cloud/tests/render-compare.sh`）。开发模式直接替换这套环境中的 bff / web。
2. **入口**：Envoy Gateway（与本地一致，保留入口追踪）+ 云负载均衡器 + cert-manager（Let's Encrypt HTTP-01，Gateway API 求解）。
   不修改集群托管的 Gateway API CRD：Envoy Gateway v1.9.2 自带的正是 v1.6.1，Helm 跳过已存在的 CRD（R2 实测）。
3. **身份**：集群内自带 Keycloak；导入时一并创建工具与 e2e 使用的导入服务账号（本地仍由负责人手工创建）。
4. **镜像**：bff / web 在集群内用 BuildKit 构建（buildkitd 平时 0 副本，开发机只运行 buildctl）；OpenMetadata 相关镜像只由手动触发的
   GitHub Actions 流水线构建，并做 SBOM、许可与漏洞扫描后推送。最近一次部署的版本即稳定版本，记录来源与是否含未提交改动。
5. **开发模式**：DevSpace 替换 Pod 并同步源码（实测约 1 秒生效），结束时显式 `reset pods` 恢复；开发模式中部署前须先结束开发模式
   （Helm 更新会让原 Pod 与开发 Pod 同时运行，R11 实测）。
6. **测试**：一次性工具箱 Pod（docker:dind 边车）对开发机工作区运行现有测试，集成测试代码与本地相同；bash 脚本覆盖率用 kcov 统计并纳入门禁。
7. **启停**：按依赖顺序缩容 / 恢复工作负载（副本数记在注解中），CNPG 休眠，暂停定时任务；弹性池由集群自动扩缩释放到最小节点数。
8. **可移植性**：脚本与通用模板只用标准 Kubernetes API 与开源组件；云厂商专用值（节点池标签、负载均衡器注解、存储类、镜像仓库）
   全部来自配置，由渲染测试检查不泄漏。
9. **组件登记**：cert-manager、BuildKit、CI 工具箱按组件目录登记，标记 `delivered: false`，不进入离线交付包。

## 许可例外

kcov 为 GPL-2.0，只用于 CI 工具箱与 CI 运行器统计 bash 覆盖率，不进入任何交付物或运行时镜像；登记于 `tools/license-allowlist.yaml`。

## 被否决的替代方案

| 方案 | 否决原因 |
| --- | --- |
| 两套环境（共享环境 + 只含 bff / web 的开发环境） | 负责人决定合并为一套，减少域名、回调与数据库；代价是开发模式期间不适合演示 |
| 接管 Gateway API CRD（`install-policy=external`）或改用 Cilium Gateway | 前者影响集群中其他负载的 CRD 维护；后者与本地入口实现不一致。实测兼容后均不需要 |
| DNS-01 通配符证书 | 要求域名托管在支持的 DNS 服务商并提供 API 令牌 |
| Kaniko 集群内构建 | 上游已于 2025 年归档 |
| DevSpace / Skaffold 自带的集群内构建器 | 依赖开发机上的 `docker buildx` |
| Skaffold、Tilt 做开发模式 | Skaffold 以自身部署为中心，结束时删除资源；Tilt 的构建依赖本地 Docker |
| 集成测试改连云端环境的真实组件 | 需改写测试夹具，本地与云端行为分叉，且测试数据污染演示环境 |
| 卸载再部署代替启停 | 慢，且依赖重建数据卷绑定 |
| bashcov 统计 bash 覆盖率 | 需另装 Ruby 运行时 |
