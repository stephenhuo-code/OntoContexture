## 待负责人确认（D1–D7）

| # | 问题 | 原型当前做法 | 备选 |

| D7 | 来源展示的粒度 | 资产名 + FQN + OM 版本 + 读取时间 | 只显示资产名与链接 |

## 原型中的示意说明

- 工作台区域仅示意 Omnigent v0.18.0 的布局结构，不复刻其 UI；生产以官方嵌入产物为准。
- 工具名「OM MCP · 读取资产详情 / 血缘 / 搜索」为示意，实际工具名以锁定的 OM MCP 版本为准，在 plan 中核对。
- 错误码（`OMNIGENT_UNAVAILABLE`、`OM_UNAVAILABLE`、`EXECUTION_NOT_ENABLED`）为占位，正式命名在契约中定义。
- 口径差异组件的数据属于 015，007 只交付渲染组件与契约；原型中的口径内容为组件样例。
