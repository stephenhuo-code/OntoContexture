## 原型交互走查指引

直接双击或在浏览器打开 [`specs/006-asset-search-summary/prototype/index.html`](index.html) 即可离线体验全部交互：

1. **顶部演示工具栏（12 个预设状态一键切换）**：
   - **1. 默认探索（浏览树）**：无搜索词时，左侧二级栏显示 OM Explore 风格的层级浏览树（`数据库 → 服务类型 → 服务 → 库 → Schema` 及 `治理与语义 → 术语 / 标签`）。点击任意节点只向中间列表施加 `browsePath` 位置过滤条件（生成蓝色位置胶囊），不跳离当前探索页。
   - **2. 关键词检索+高亮（类型计数）**：搜索 `质检`，左栏自动切换为命中计数大于 0 的资产类型列表（`entityTypeCounts`），卡片标题、描述与摘要列清单均带关键词高亮（`<span class="text-highlighter">`）及命中字段统计。
   - **3. 同名表辨识（`material`）**：并列展示 `mock-mes.default.mes.material`（005 真实采集，数据级别：二级）与 `dev-import-erp.default.erp_mdm.material`（006 开发态导入，数据级别：三级），直观辨识所属服务、业务域、负责人、分级（Tier）与数据安全级别。
   - **4. 缺失属性排查（无负责人 / 无 Tier）**：演示快速筛选中的 `无 (未分配 / 缺失该属性)`（对应 OM `OM_NULL_FIELD`），一键筛出尚未认领负责人或未定级的 `stg_equipment_alarm_raw`。
   - **5. 无匹配结果**：空状态提示与一键清除条件，右侧摘要面板自动关闭。
   - **6. 加载中**：骨架屏加载态。
   - **7. OM 检索/索引异常**：展示真实的后端错误码（`OM_SEARCH_INDEX_UNAVAILABLE`）与排查引导，不回退内置示例数据。
   - **8. 零资产初始态**：尚未接入或导入任何资产时的空状态引导。
   - **9. 子视图：数据源管理 (005)** 与 **10. 子视图：资产详情 (005)**：演示如何在同一个「数据资产」页面内承接 005 的数据源管理与资产详情编辑，并可随时通过左栏浏览树或返回按钮回到探索视图。
   - **11. 子视图：术语详情（只读）**：006 新增的业务术语 / 分类标签只读详情页示意（无编辑入口；字段清单以 plan 阶段按 OM 实体定义为准）。
   - **12. 列结果 → 表详情定位**：点击列结果后进入所属表的 005 详情，字段表定位并高亮该列。
2. **顶栏搜索框与防抖建议浮层**：
   - 在顶栏搜索框输入关键词（如 `order_no` 或 `material`），自动弹出按资产类型分组的建议浮层（每组最多 5 条）：**点击建议项直接进入该资产详情子视图，按 `Enter` 在列表中按相关性排序展示**。
3. **右侧只读摘要面板（`EntitySummaryPanel`）**：
   - 点击任意结果卡片联动更新右侧摘要，包含 `概览 (Overview)` 与 `Schema / 字段` 两个页签，明确区分 **资产分层 (Tier)**（业务重要度）与 **数据安全级别**（ADR-0008 一级/二级/三级敏感定级），按 `Esc` 或点击 `×` 可关闭。
