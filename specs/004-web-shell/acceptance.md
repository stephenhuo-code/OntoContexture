# 004 用户验收

**状态：已验收通过并关闭（2026-11-03，产品负责人确认）。**
验收入口：[织境首页](http://localhost:8080/home)。建议预留 15 分钟。

## 1. 你需要验收的内容

检查你在织境中实际使用的登录、退出、账号、导航、页面布局和未开放提示是否符合预期。
你只需要打开上述入口并使用页面。开发组件演示、故障模拟、自动化测试、接口与兼容性检查由开发侧完成。

使用已经提供的 engineer1 或 admin1 测试账号即可。

## 2. 操作步骤

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1. 登录与账号 | 打开首页，点击“使用企业账号登录”，查看浅蓝品牌页；在企业认证页按提示输入测试账号、密码；进入后展开右上角账号 | 登录入口和企业认证页视觉一致，表单和按钮清晰；能登录；显示真实账号和对应角色；展开后可以查看完整账号信息 |
| 2. 退出与再次登录 | 点击“退出”，刷新页面；再点击“使用企业账号登录” | 退出后显示登录入口，旧用户页面不可继续使用；再次登录要求重新认证，输入正确密码后才能进入 |
| 3. 导航 | 依次点击“新建对话、首页、资产搜索、Agent 工作台”；在首页切换“概览、审批中心” | 页面标题与所选入口一致；能清楚知道自己在哪个页面；返回首页正常 |
| 4. 菜单与返回 | 在首页收起二级菜单，切到资产搜索再回首页；展开菜单；使用浏览器前进、后退和刷新 | 收起后正文空间变大，展开按钮容易找到；切页时保留收起状态，刷新后默认展开；前进、后退后页面和选中项正确 |
| 5. 首页与建设状态 | 查看首页问候、四项概览区域、“我的待办”和“最近浏览资产”；进入尚未开放的页面 | 问候使用真实账号；没有真实来源的区域说明“尚未接入”或“尚未开放”，没有假数量、假资产或假待办；未开放页面有说明和返回首页操作 |
| 6. 页面使用体验 | 在日常使用的窗口中查看页面、调整窗口大小，操作导航和账号；也可用 Tab / Enter 操作 | 文字能看清，内容和按钮不互相遮挡；账号和主要入口始终可操作；页面没有整体横向溢出，键盘焦点可见 |

本次验收的是可登录、可导航、可退出的产品外壳。数据接入、资产搜索、Agent 对话和审批处理随后续特性开放，
当前相应页面显示“尚未开放”符合本次范围。
