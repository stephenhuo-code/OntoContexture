# UI Contract: 004 外壳

设计契约，产品实现尚未生成。依据 spec 的 US1 / US2、D1 / D2，不实现后续业务页面。

四个一级入口顺序：新建对话、首页、资产搜索、Agent 工作台。当前 action 的 aria-label / 页面标题可区分，
不得产生两个互相矛盾的当前位置；首页二级只有本期的概览与审批中心。
深链、刷新和前后退恢复实际路径；登录 return_to 仅允许安全站内路径和查询，拒绝站外 / 反斜杠等不安全值。

## 身份和操作

- 页根检查 Me；checking 不显示旧用户，401 显示登录入口，403 显示无权限和退出，502 / 500 显示错误与重试。
- 账号显示名 → user_id 回退；允许完整身份通过可访问文本 / 提示读取。不用原型固定账号与角色冒充身份。
- logout 非 204 不显示“已退出”；成功后清 Me / 业务缓存、停留匿名页；重新登录是独立操作。
- 已认证但不准入用户不显示外壳业务内容，禁止登录循环；返回 / 退出操作仍可达。
- 登录回调的取消 / 失败按 [bff-session.md](bff-session.md#登录导航失败与恢复) 回到 `/auth/error`。
  reason 仅允许 cancelled / invalid_response / unavailable / internal；未知值显示通用失败说明，拒绝直接展示上游错误描述。
  “重新登录”发起全新认证请求，“返回首页”经过正常身份检查；不复用失败 code / state，不自动跳 SSO。
  该路径在会话门禁之前匹配，只渲染恢复说明；页面参数不能授予角色、填充账号或读取业务数据。

## 布局和视觉

- 亮色：原型深色一级栏、浅色内容背景、白色面板、蓝色主操作；提炼语义 tokens，不复制 inline-style 实现。
- 以一级栏约 76px、二级菜单约 232px、页头最小约 60px 为原型基准；按 spec 两种桌面尺寸校验内容不整体横向溢出。
- 二级收起后仍有有名称的展开按钮；同次应用使用保留，刷新默认展开。
- 首页指标 / 最近资产 / 待办保留版式，使用“尚未接入 / 尚未开放”；没有来源时不显示 0、假日期或模拟统计。
- 004 隐藏顶栏搜索和问 Agent；未来特性接入不改变外壳身份模型。功能编号只在工程文档使用。
- 简体中文集中管理；系统中文字体栈和本地资源，运行时不依赖 Google Fonts 等外站加载。
- 导航采用语义链接或按钮、aria-current / accessible name、可见 focus；tooltip 同时覆盖聚焦与悬停，不只用颜色标选中。

## 公共包与示例

`@contexture/ui` 负责 Button、TextInput、Panel、StatusBadge、PageState、Tooltip 等本期必要基础原语与 tokens，
React 作为 peer dependency，禁止引入第二份 React。业务路由、角色准入、查询服务不属于 UI 包。

示例覆盖主 / 次、disabled、focus、busy，以及 loading / empty / error / forbidden / not_open；
包含真实交互状态的本地展示，不调用后续业务服务。PageState error 接受安全重试函数，其他状态仅提供实际可用动作。
无需 Storybook，不增加演示服务；示例不打入普通用户菜单且生产不开放该路由。
